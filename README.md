# A.R.I.A. V7 — Classified Archive

A standalone HTML/CSS/JS lore website designed as a fictional confidential Helix Advanced Robotics archive. The Visual Archive gallery uses three local image assets in `assets/`.

## Files
- `index.html` — entire website content, including the Visual Archive gallery
- `style.css` — visual design and responsive gallery styling
- `script.js` — archive navigation interaction
- `assets/` — A.R.I.A. outfit and design reference images

## GitHub Pages
1. Upload the contents of this folder to the root of your repository, keeping the `assets` folder beside `index.html`.
2. In GitHub, open **Settings → Pages**.
3. Under **Build and deployment**, select **Deploy from a branch**, choose `main` and `/(root)`, then save.
4. Wait for the Pages deployment to finish, then open the URL shown in Settings → Pages.

For an existing deployment, replace `index.html`, `style.css`, and `README.md`, then upload the complete `assets` folder and its three images. Keep `script.js` if it is already in the repository; it is unchanged.
