# A.R.I.A. V7 — Classified Archive

A standalone HTML/CSS/JS lore website designed as a fictional confidential Helix Advanced Robotics archive.

## Files
- `index.html` — entire website content
- `style.css` — visual design
- `script.js` — small navigation interaction

## Easiest free hosting
### GitHub Pages
1. Create a GitHub repository.
2. Upload these three files to the repository root.
3. Go to Settings → Pages.
4. Select "Deploy from a branch", choose `main` and `/root`.
5. GitHub will provide your public site URL.
6. Put that URL into your guns.lol profile as a custom URL.

### Alternative
You can also upload the folder to another static hosting service such as Cloudflare Pages or Netlify.

## guns.lol
guns.lol works best here as the public profile / link hub. Add the archive URL as a custom link on your guns.lol profile. The archive itself remains a separate website, which allows the lore to be much larger than a normal guns.lol bio.
